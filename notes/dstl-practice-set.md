## How to use this practice set

Try each question first, then open it to check your answer.

?? If A = {1, 2, 3}, how many subsets does A have?
|A| = 3, so the power set has 2³ = **8** subsets, including ∅ and A itself.

?? Is the relation R = {(1,1), (2,2), (3,3), (1,2), (2,1)} on {1, 2, 3} an equivalence relation?
**Yes.** It is reflexive, because (1,1), (2,2) and (3,3) are all present. It is symmetric, because (1,2) and (2,1) are both present. It is also transitive: every chain, such as (1,2) followed by (2,1), gives a pair, here (1,1), that is already in R. The equivalence classes are {1, 2} and {3}.

?? Write the contrapositive of "If it rains, then the ground is wet."
"If the ground is **not** wet, then it did **not** rain." It is logically equivalent to the original statement.

?? Show that (p → q) ∧ (q → p) is equivalent to p ↔ q.
By definition, p ↔ q is true exactly when p and q have the same truth value. Building the truth table for (p → q) ∧ (q → p) gives T, F, F, T for the rows TT, TF, FT and FF, which is the same as p ↔ q.

?? Is f(x) = 2x + 3 from ℝ to ℝ a bijection?
**Yes.** It is one-one, because 2x₁ + 3 = 2x₂ + 3 implies x₁ = x₂. It is onto, because for any y, x = (y − 3)/2 satisfies f(x) = y. Its inverse is f⁻¹(y) = (y − 3)/2.

?? In a class of 60 students, 35 study Python and 30 study Java, and 10 study both. How many study neither?
|P ∪ J| = 35 + 30 − 10 = 55, so 60 − 55 = **5** students study neither.

?? Is p ∨ ¬p a tautology, a contradiction or a contingency?
It is a **tautology**: whatever the value of p, one of p and ¬p is true.
